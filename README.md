# Enterprise-RAG-Engine

AI-powered Retrieval-Augmented Generation (RAG) application for PDF-based question answering using LangChain, FastAPI, ChromaDB, React, and Ollama.

---

## 🚀 Features

- Upload PDF documents
- Extract and process document text
- Semantic search using vector embeddings
- AI-powered question answering
- Local LLM support using Ollama
- FastAPI backend
- React frontend UI
- ChromaDB vector database

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS

### Backend
- Python
- FastAPI
- LangChain

### AI & Vector Database
- Ollama
- Llama 3.2
- nomic-embed-text
- ChromaDB

### Document Processing
- PyPDF
- LangChain Text Splitter
